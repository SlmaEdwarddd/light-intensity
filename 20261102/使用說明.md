# 光強度量測程式 使用說明(20261102 版)

## 一、使用流程

1. **開程式,選相機**
   選「FLIR Blackfly S」→ 按 **Initialize / 初始化**。
   (只分析照片的話,選「匯入圖片」再選檔案。)

2. **放好載玻片,確認 ROI**
   程式會自動在每個樣本上放好框(ROI)。
   - 框沒對準 → 按 **重新對位 / Re-align samples**
   - 框太大或太小 → 拖 **ROI 大小** 滑桿
   - 狀態欄出現紅字「尚未校正」→ 請找管理者(見第三節)

3. **設定相機**
   填 **Gain**、**Exposure(ms)**,各按一次 **Apply**。

4. **亮度校正(建議開)**
   在「亮度校正」選 **背景估計 / Background fit**。
   - 有**沒框到的亮樣本**(例如 control)→ 按 **畫背景排除區**,用滑鼠框住它,框完按 **結束畫排除區**
   - 有 blank(negative control)→ 按 **擷取平場**,選「S? 是 blank」→ 確定
   - 想看校正效果 → 按 **預覽校正**

5. **量測**
   按 **開始 / Start** → **至少量 30 秒** → 按 **停止 / Stop**。
   (前 10 秒不算進統計,量太短會沒有數據。)

6. **存檔、畫圖**
   按 **儲存 CSV**,選存檔位置,接著跳出「製作圖表?」→ 選「是」:
   - 選 **對半稀釋**(只填最高濃度)或 **自訂**(每個樣本填濃度)
   - **濃度 0 的樣本要填 0,不要勾「不參與統計」**
   - blank 已經自動勾好,不用動
   - 按 **確定**,圖會存在 CSV 旁邊

## 二、守則

- **要互相比較的量測,Gain、Exposure、光源都要一樣。** 中途改了,之前的數據就不能比。
- **量測中不要碰載玻片、相機和設定。**
- **不要移動相機或載玻片座。** 動到了,ROI 會對不準,要請管理者重新校正。
- 環境光要一致(關燈或每次都同樣條件)。
- 存檔前確認每個框都在樣本上、沒有框到反光或灰塵。
- 有問題先截圖畫面(含狀態欄文字)再回報,不要自己改設定檔。

## 三、管理者才需要做的

**載玻片位置校正**:換相機、相機或載玻片座被移動過、或狀態欄顯示「尚未校正」時才需要做。

1. 進階設定 → 按 **校正載玻片位置(點 3 格)**
2. 依序點 **T1(上排最左)→ T8(上排最右)→ B1(下排最左)** 的中心
3. 完成後自動存檔,下次開程式會直接套用
