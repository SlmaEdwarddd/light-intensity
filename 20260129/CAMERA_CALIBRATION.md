# 相機比例尺校準 / Camera Scale Calibration

## Thorlabs 相機 (已自動配置)

- **型號**: Thorlabs TSI Camera
- **分辨率**: 4096 x 2160 pixels
- **像素尺寸**: 3.45 μm x 3.45 μm per pixel
- **轉換比例**: 0.2899 pixels/μm (自動設定)

該程序已自動為 Thorlabs 相機設置此參數。初始化後，比例尺會自動啟用。

---

## XIMEA 相機 (需手動配置)

如果使用 XIMEA 相機，請按以下步驟配置比例尺：

### 第一步：確定你的 XIMEA 相機規格
- 查找相機的分辨率 (W × H pixels)
- 查找相機的像素尺寸 (μm per pixel)

### 第二步：計算轉換比例
```
像素/微米 = 1 / (像素尺寸μm)
```

**例子**:
- 如果像素尺寸 = 2.0 μm per pixel
- 則轉換比例 = 1 / 2.0 = 0.5 pixels/μm

### 第三步：在設定區輸入
在「比例尺 / Scale Bar」區域中：
1. 勾選「顯示比例尺 / Show Scale Bar」
2. 在「像素/微米 (px/μm)」欄位輸入計算出的轉換比例
3. 設置「比例尺長度 (μm)」為你想要顯示的長度（預設 50μm）
4. 可選：勾選「標示距離 / Show Distance Label」顯示 ROI 的尺寸

---

## 使用比例尺

程序啟動後：

1. **選擇相機** → Thorlabs 的比例尺會自動設置
2. **選擇 ROI** → 畫面上會自動顯示比例尺
3. **開始量測** → 實時顯示 ROI 區域的寬高或直徑
4. **右鍵點擊圖表** → 保存帶有比例尺的圖表

## 驗證比例尺正確性

1. 在設定中輸入轉換比例
2. 在視野中畫一個已知大小的 ROI
3. 檢查顯示的尺寸是否合理
4. 如有誤差，調整轉換比例值
