# 透鏡倍率配置指南 / Lens Magnification Guide

## 功能説明

當相機前面安裝了透鏡時，可以通過設置透鏡倍率來自動調整比例尺和尺寸顯示。

## 如何設置透鏡倍率

### 步驟 1：找到「透鏡倍率」設置區
在右側設定面板中，找到「透鏡倍率 / Lens Magnification」區域。

### 步驟 2：輸入倍率值
- **無透鏡時**：輸入 `1.0`（預設值）
- **使用透鏡時**：輸入透鏡的倍率
  - 例：`2` 或 `2.0` （2倍透鏡）
  - 例：`5` 或 `5.0` （5倍透鏡）
  - 例：`10` 或 `10.0` （10倍透鏡）
  - 支持小數值，例：`1.5`、`2.5`、`3.3` 等

## 透鏡倍率的影響

### 比例尺顯示
- 比例尺會根據倍率自動調整
- 顯示的比例尺值會包含倍率標記，例：`50um (2.0x)`

### 距離標籤
- ROI 的實際尺寸會根據倍率重新計算
- 對於矩形 ROI：`W:X.Xum H:X.Xum (2.0x)`
- 對於圓形 ROI：`Φ:X.Xum (2.0x)`

### 計算方式
```
實際像素/微米 = 基礎轉換比例 × 透鏡倍率

例如：
- 基礎轉換比例（無透鏡）= 0.2899 px/um
- 透鏡倍率 = 2.0x
- 實際轉換比例 = 0.2899 × 2.0 = 0.5798 px/um

這意味著在視野中的物體看起來大2倍，
所以同樣的像素尺寸對應的實際微米數會減半。
```

## 常見透鏡配置

### 典型光學顯微鏡透鏡倍率
| 倍率 | 應用場景 |
|------|---------|
| 1.0 | 無透鏡（直接相機） |
| 2.0 | 低倍率觀察 |
| 5.0 | 中等倍率觀察 |
| 10.0 | 高倍率觀察 |
| 20.0 | 超高倍率觀察 |

## 實時預覽

設置完透鏡倍率後：
1. 在視窗上畫 ROI
2. **勾選「標示距離 / Show Distance Label」**
3. 即時查看帶有倍率信息的尺寸標籤
4. 如果倍率為 1.0，標籤中不會顯示倍率標記

## 驗證透鏡倍率

1. **使用已知尺寸的物體進行測試**
   - 例：已知微珠或網格的尺寸
   
2. **對比計算結果**
   - 顯示的尺寸應該與實際尺寸相符
   
3. **調整倍率值**
   - 若顯示的尺寸過大，增加倍率
   - 若顯示的尺寸過小，減少倍率

## 注意事項

- 透鏡倍率只影響尺寸顯示和比例尺，**不影響相機採集的圖像本身**
- 倍率值必須為正數，小數點後最多一位會被顯示
- 在「顯示比例尺 / Show Scale Bar」啟用時，倍率才會生效
- 修改倍率值會立即更新顯示（無需重新啟動程序）

## 常見問題

### Q：如何知道我的透鏡倍率？
A：檢查透鏡上的標記或相關的光學元件文檔。通常會標註為「2x」、「5x」等。

### Q：倍率可以是小數嗎？
A：是的，支持任何正數值，例如 1.5、2.3、3.7 等。

### Q：改變倍率後需要重新選擇 ROI 嗎？
A：不需要。倍率改變只影響尺寸計算，現有的 ROI 選擇會自動用新的倍率重新計算尺寸。

### Q：如果沒有透鏡應該輸入什麼？
A：輸入 `1.0` 或 `1`，這是預設值，不會改變計算結果。
